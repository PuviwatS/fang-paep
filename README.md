# ฟังแป๊บ — เดโมเกมทายเพลงไทย (MVP)

เดโมเกมแนว Songless สำหรับเพลงไทย: ฟังท่อนสั้น 0.5 วินาที ทายผิดหรือกดข้ามจะได้ฟังยาวขึ้น (0.5 → 1 → 2 → 4 → 8 → 16 วินาที) รวม 6 ครั้ง

## วิธีรัน

```bash
npm install
npm run dev
# เปิด http://localhost:3000
```

ต้องต่ออินเทอร์เน็ต เพราะเสียงตัวอย่างโหลดจาก iTunes ตอนเล่น

## มีอะไรในเดโมนี้

- เพลงประจำวัน แยกตามหมวด: ทั้งหมด / ป๊อป-อินดี้ / ร็อก / ลูกทุ่ง / ฮิปฮอป (เปลี่ยนเพลงตอนเที่ยงคืนเวลาไทย และไม่ซ้ำจนกว่าจะครบทุกเพลงในหมวด)
- โหมดสุ่มเล่นไม่จำกัด
- ค้นหาเพลงได้ทั้งชื่อเพลงไทย/อังกฤษ ชื่อศิลปิน และชื่อศิลปินภาษาไทย เช่น "บอดี้สแลม", "ต่าย อรทัย"
- ผลทาย 3 สี: เขียว = ถูก, เหลือง = ศิลปินถูกแต่ผิดเพลง, แดง = ผิด
- แชร์ผลเป็นข้อความอีโมจิ, เก็บสถิติและสตรีคในเบราว์เซอร์ (localStorage)
- ตำแหน่งโฆษณาและการ์ดสมาชิก "พลัส" เป็นตัวอย่างวางเลย์เอาต์เท่านั้น ยังไม่ได้ต่อระบบจริง

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `data/songs.json` | คลังเพลง 240 เพลง: `[iTunes trackId, ชื่อเพลง, ศิลปิน, หมวด, ปี]` |
| `data/artists.json` | ชื่อศิลปินภาษาไทยสำหรับช่องค้นหา |
| `lib/game.ts` | ตรรกะเกม: เลือกเพลงประจำวัน, ค้นหา, ตรวจคำตอบ, ข้อความแชร์, เรียก iTunes Lookup |
| `components/Game.tsx` | หน้าจอเกมและเครื่องเล่นเสียง |
| `scripts/fetch_itunes.py` | ดึงรายชื่อเพลงของศิลปินจาก iTunes Search API ออกมาเป็น CSV เพื่อคัดเลือกเพิ่ม |

## เรื่องเสียงและลิขสิทธิ์

เว็บเก็บแค่ `trackId` แล้วเรียก `https://itunes.apple.com/lookup?id=...&country=th` ตอนเล่น เพื่อเอา URL ตัวอย่างเสียง 30 วินาทีของ Apple มาเล่นโดยตรง ไม่ได้ดาวน์โหลดหรือเก็บไฟล์เพลงไว้เอง และมีลิงก์ "ฟังเต็มเพลงบน Apple Music" ในหน้าเฉลย

เดโมนี้ใช้ทดสอบว่าคนอยากเล่นไหมเท่านั้น ก่อนใส่โฆษณาหรือเก็บค่าสมาชิกจริง ต้องตรวจเงื่อนไขการใช้งานของ Apple และขอสิทธิ์จากค่ายเพลงหรือหน่วยงานจัดเก็บลิขสิทธิ์ และควรปรึกษาทนายด้านทรัพย์สินทางปัญญา

## ขั้นต่อไปตาม stack ที่วางไว้

1. ย้าย `songs.json` ไปเป็นตาราง `songs` ใน Supabase (Postgres) และทำหน้าแอดมินเพิ่มหรือแก้เพลง
2. ใส่ Umami หรือ GA4 วัดจำนวนผู้เล่นรายวันและอัตรากลับมาเล่นซ้ำ
3. ล็อกอิน + เก็บสถิติบนเซิร์ฟเวอร์ แทน localStorage
4. เมื่อได้สิทธิ์เสียงแล้ว ค่อยเก็บคลิปบน Cloudflare R2 และเลือกจุดเริ่มท่อนเองได้
5. ต่อ AdSense และระบบสมาชิก (Stripe หรือ Opn Payments ที่รองรับ PromptPay)
